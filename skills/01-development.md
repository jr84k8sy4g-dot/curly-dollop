- Animate components, https://animejs.com

## HISTORY

- Log changes in ./agent/history.md
- Log bugs with:
    - message
    - file
    - line
- Follow this format:
    - **Version**
    - **Date**
    - **Title**
    - **Brief Summary**

    Where:
    - **Version** is auto-generated based on the last version number in the history.
    - **Date** is when the error occurred or when the feature/change was added.
    - **Title** is the task title or "BUG" for errors.
    - **Brief Summary** describes the task or includes the error message.
